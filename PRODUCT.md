# Product

## Register

product

## Users
Adultos 25-50 años en Argentina que organizan o participan en grupos deportivos amateurs
(fútbol, pádel, básquet) y grupos comunitarios (trabajo, clubes). Organizadores gestionan
cuotas, tareas y comunicación; miembros consultan novedades, pagan y coordinan.

## Product Purpose
Plataforma todo-en-uno para que grupos se organicen: gestión de miembros con roles,
finanzas (cuotas/gastos/campañas), comunicación (novedades/comentarios), agenda, tareas
y archivos. Éxito = el tesorero deja el Excel, el grupo deja el WhatsApp para lo formal.

## Brand Personality
Simple, directa, cálida. No corporativa, no atlética de élite. Cercana como un grupo
de amigos bien organizado.

## Anti-references
- Apps de gestión empresarial tipo Monday/Asana (demasiado frío y corporativo)
- Apps deportivas de élite tipo Strava/Nike (demasiado atlético, no comunitario)
- SaaS genérico (cream backgrounds, hero metrics, glassmorphism)
- WhatsApp / grupos informales (sin estructura, sin roles)

## Design Principles
1. Claridad antes que densidad — cada pantalla tiene una tarea principal
2. Calidez sin informalidad — cercano pero confiable para manejar plata
3. Rol visible — el usuario siempre sabe qué puede hacer y qué no según su rol
4. Cero fricción para el no-técnico — el tesorero de 55 años tiene que poder pagar
5. Multiplataforma real — desktop para admins, mobile para miembros en cancha

## Accessibility & Inclusion
WCAG AA mínimo. Considerar usuarios mayores (texto legible, botones grandes).
Mercado hispanohablante, solo español.
